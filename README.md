# AboutMe
This is a personal website for self introducing. It is hosted on Github Pages and can be visited through this [link](https://zyndesu233.github.io/AboutMe/).

## Tech Stack
- Vite: Web builder
- React: Fontend framework
- TailwindCSS: CSS framework
- GSAP: Web animation framework

## Built Version
The source code of built version can be viewed in [gh-pages](https://github.com/Zyndesu233/AboutMe/tree/gh-pages) branch.

## File Structure
- All `.ts`, `.tsx`, and `.css` files are stored under `src/` directory
- All react components are stored under `src/components/` directory
- All data are stored under `src/data/` directory as `.ts` files and to be exported as object
- All images are stored under `src/imgs/` directory
- In some subdirectory of `src/imgs/` contains a `README.md` listing image convension
