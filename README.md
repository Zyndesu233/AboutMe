# AboutMe
This is a personal website for self introducing. It is hosted on Github Pages and can be visited through this [link](https://zyndesu233.github.io/AboutMe/).

The tech stack is listed as follows:
- Vite: Web builder
- React: Fontend framework
- TailwindCSS: CSS framework
- GSAP: Web animation framework

The source code of built version can be viewed in [https://github.com/Zyndesu233/AboutMe/tree/gh-pages](gh-pages branch).

The design of the website is inspired from [ブシロードゲームズ](https://bang-dream-on.bushimo.jp/).
